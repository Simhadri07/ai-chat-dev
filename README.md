# AI Chat

A lightweight Python web chat app with a simple UI.

## Features
- Simple web UI for sending prompts
- Optional right value field
- JSON endpoint for chat requests

## Prerequisites
- Python 3

## Getting started
1. Install Python 3.
2. Run `python3 app.py` to start the web UI.
3. Open http://localhost:8000/ in your browser.

## Usage
- Enter your API key, prompt, and optional right value.
- Click Send to submit the message.
